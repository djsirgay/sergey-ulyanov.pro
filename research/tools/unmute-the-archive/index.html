Archive Passport — Unmute Belarus

Document a recording’s origin, cultural context, rights and reuse history. This browser-based research pilot creates archival passports, checks exact file identity and exports records for preservation or analysis.

The interactive tools calculate SHA-256 fingerprints locally, keep source and derivative records distinct, and export JSON or CSV. A fingerprint identifies file bytes; it does not establish authorship, ownership or historical truth. Audio is not uploaded by the core passport workflow.

JavaScript is required to create and verify passports. While the application loads, or if it cannot start, the research context and related tools remain available below.
