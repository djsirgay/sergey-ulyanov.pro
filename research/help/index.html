Music Atlas · Discovery and evidence

Music search

  1. Open the public-catalog search. Type a description such as “Belarusian folk”, an artist’s name, or “electronic music 1990s”.
  2. Check “Edit how the description is interpreted”. Adjust style, format, dates and work language, then choose “Search the public catalog”. A musician’s nationality is not the language of every song.
  3. Inspect the result and follow its source link. Artist leads and individual works are different result types. Mood is a preference to investigate, not a verified filter.
  4. Use “Export these source records” to save the catalog results. For your passports and curated examples, move to “Explore the local corpus”, open a dossier, and inspect or add a local annotation.

Two collections, not one giant archive: the live public catalog uses Wikidata metadata; the local corpus contains curated source records and this browser’s passports. A zero-result search does not prove that music does not exist. Broaden a criterion or try another spelling. Search-result exports are not full browser backups.

Archive Passport · Document before transforming

Recording passport

  1. Choose an audio file you are entitled to use, or select the missing-source route if the recording is unavailable. The browser computes an available file’s SHA-256 fingerprint locally; the audio is not uploaded.
  2. Complete the required title, creator, language, place, collection, context and rights information. Use “Other” where needed; document unknown dates honestly rather than guessing.
  3. Choose “Create archival passport”. If a required field is missing, the form lists what to complete. A successful result shows a passport ID, source status and citation.
  4. Download the passport JSON and keep your original audio separately. Open the local corpus to see your saved records, or use the verification section to compare the same file against its passport.

An exact fingerprint match proves identical bytes, not ownership, historical authenticity or a match between differently encoded versions. Missing-source records have no source fingerprint. Browser storage alone is not a backup.

Restoration Lab · Preserve the source, document the change

Audio lab

  1. For a first test, choose “Run a safe synthetic demo”. For your own recording, create or import its passport first, select that passport, and choose the exact source audio file.
  2. Check the source-match message. Set the low-rumble filter, high-frequency limit and level options. State the purpose of the change and add a reviewer note if useful.
  3. Choose “Process documented derivative”. Listen to source A and derivative B. Decide whether the change improves access without hiding information you need.
  4. Download the WAV and JSON log. If the source fingerprint matches its passport, choose “Register in passport” to save the derivative’s fingerprint and method alongside the original history.

This is a conservative listening-copy workflow, not automatic historical restoration. It does not separate stems, transcribe lyrics or reconstruct missing audio with AI. Downloads are 16-bit PCM WAV; keep the original master and the processing log.

Living Belarus Atlas · Find the people and sources

Culture directory

  1. Enter a topic or choose an example, such as podcasts about music or short videos about language.
  2. Narrow the results with format, topic and language. All active filters apply together; reset a filter if nothing matches.
  3. Open a result and read the original publisher’s resource. The directory’s description is a research annotation, not a replacement for the source.
  4. If you know a missing resource, use “Suggest a source” to prepare an email with its original URL and a short explanation. You choose whether to send it.

The directory is a curated seed index. It does not mirror every linked website, automatically collect contributors’ archives, or imply that a listed person endorses the research.

MAPA · The same lands, different states

Historical map · MAPA

  1. Choose a period in the shared historical selector. A mapped date opens territorial geography; a context-only stage opens its explanation without inventing borders.
  2. Read the country labels and colored legend. Switch between the modern-Belarus reference area and the wider region to see surrounding states.
  3. Select a place from the city control, map or affiliation table. Read which source polity contains it at that date. Compare Brest in 1938 and 1945 as a quick test.
  4. Use the chronology and source notes to distinguish sovereignty, occupation, territorial claims and unresolved detail. Change the language without losing your selected period.

Current coverage: seven dated map snapshots, 28 chronology stages and 25 place checks. Today’s Belarus outline is only a fixed orientation reference. This independent edition credits the original MAPA creators; it is not a restoration of all 63 original maps.

Where does my data go?

Passport → Audio lab → Local music collection is a documented relationship, not an automatic upload pipeline. The tools share passport metadata within one browser and website address. A linked derivative appears with its parent passport; audio stays in your own files. The public catalog, cultural directory and map remain separate source collections.

Switching devices, browsers or website addresses does not automatically move saved records. Download a full browser backup below to preserve both passports and music annotations. Do not clear the old site’s data before checking the import.
